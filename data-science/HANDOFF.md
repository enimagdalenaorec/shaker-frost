# PriPreMa data handoff (2026-10-08, Zagreb)

Food products sold in Zagreb with current prices, price opportunities, vegan class with evidence, nutrition per 100 g / 100 ml with the source of every value, and a standardisation concept for search. Generated by `data-science/pipeline/scripts/08_export.py` (pipeline and decisions: `reports/pipeline_README.md`). All files join on `product_key`.

## How the app uses it

- **Vegan filter.** Only `vegan_class = 'vegan'` enters cart totals; `potencijalno_vegan` goes to the 'provjeri' list; `nesigurno` and `nije_vegan` are hidden. Counts: nesigurno 44,617, nije_vegan 27,005, vegan 11,834, potencijalno_vegan 6,919.
- **Prices.** `store_prices` for one store or the best set of stores, `offers` for the cheapest store per chain. A price is 'zadnja zabilježena cijena' with its date; `stale` prices are kept and flagged. Only `akcija` (retailer's special price) is called a sale; `prilika` = >= 5 % below the monthly median.
- **Nutrition chips.** Sort by a nutrient; products whose `nutrition_nedostaje` contains it go last with `nutrition_praznina_opis`. Show `nutrition_izvor_opis` as the badge, and 'procjena' when `nutrition_procijenjeno`. An estimate is never shown as a label.
- **Search.** Model writes nominative-singular terms; match `concepts.korijeni` / `sinonimi` with LIKE, then `products.concept_id` (and descendants via `concept_put`).

## `products` columns


**Identity**

- `product_key`: EAN without leading zeros (one product across chains and shops), else `chain:product_id` or `shop:id`. Join key of every table.
- `has_barcode`: true when `product_key` is an EAN.
- `name`, `names`, `brands`: Display name (most common chain name, else shop or OFF name); all names and brands seen.
- `categories`, `sellers`, `n_chains_active`: Chain categories, chains / shops that sell it, number of chains with a current price.
- `food_method`: How the food filter decided: 'kategorija', 'ime_nb' (name classifier), 'rucno' (reviewed list).

**Vegan**

- `vegan_class`: 'vegan' (enters cart totals), 'potencijalno_vegan' (goes to the 'provjeri' list), 'nesigurno' and 'nije_vegan' (hidden).
- `vegan_reason`, `evidence_class`, `vegan_evidence`: Main reason in Croatian, evidence strength, all evidence as JSON (signal, source, text).

**Nutrition (per 100 g or 100 ml)**

- `kcal`, `fat`, `saturated_fat`, `carbohydrates`, `sugars`, `protein`, `salt`: The 7 EU label values. NULL = unknown, never 0 for unknown.
- `fiber`: Fibre when known (not one of the 7; missing is normal).
- `<nutrient>_src`: Source of that one field, see the table below. Fields of one product can come from different sources.
- `<nutrient>_etiketa`: The product's own declared label value before same-product averaging (NULL when it had none).
- `nutrition_n7`: How many of the 7 values are present (0-7).
- `nutrition_izvor`, `nutrition_izvor_opis`: Badge for the product card, from the kcal source; `_opis` is the Croatian UI text.
- `nutrition_izvori`: All source groups among the 7 fields.
- `nutrition_procijenjeno`: true when any of the 7 values is an estimate: show 'izvedeno' / 'procjena'.
- `nutrition_nedostaje`: List of the 7 fields that are missing; sort these last ('nema podataka').
- `nutrition_praznina`, `nutrition_praznina_opis`: Why values are missing (code + Croatian text); NULL when all 7 are present.
- `nutrition_note`: 'potpuno', 'potpuno (dio procijenjen)', 'djelomično', 'nije pronađeno[: reason]' or 'provjeriti: <check>' for a label that fails a plausibility check.
- `nutrition_flags`: Plausibility problems of the raw sources (shop page, OFF).
- `nutrition_ref`: Where an estimate comes from: `ciqual:<alim_code>`, `knn:<product_keys>`, `isti_proizvod:<product_keys>`, `omjer:<group>`, `web:<url>`.

**Cheapest current offer**

- `best_seller`, `best_source`, `best_price`, `best_price_date`, `best_store_id`, `best_url`: Cheapest current offer over chains and web shops (EUR); `best_url` for web shops.
- `best_stale`, `best_stale_reason`: true when only a stale price exists (not seen in the last two samples), with the reason.
- `prilika`, `akcija`, `stale`: Any offer is >= 5 % below its monthly median / the retailer publishes a special price / all offers are stale.

**Sources behind the product**

- `off_code`, `off_name`, `off_ciqual_code`, `off_rejected`, `off_ingredients`: Linked OFF record, its CIQUAL proposal, why an OFF link was rejected, ingredients.
- `shop`, `shop_url`, `shop_attributes`, `shop_ingredients`: Linked web-shop page.

**Standardisation (vegan and potencijalno_vegan only)**

- `concept_id`, `concept_naziv`, `concept_run`, `concept_obitelj`: Concept; run 'A' = vegan substitute (napitak od zobi, tofu...), 'B' = plain plant food; family.
- `concept_put`, `concept_komponente`: Path from the root concept; other concepts found in the name (e.g. rice in a rice drink).
- `std_naziv`: Standard name: concept, flavour, sweetness, purpose ('napitak od zobi, čokolada, barista').
- `atr_okus`, `atr_zasladenost`, `atr_prehrambena_svojstva`, `atr_oblik_obrada`, `atr_namjena`, `atr_porijeklo`: Attributes: flavour, sweetness, dietary properties (bez glutena...), form (sušeno, smrznuto, prah...), purpose (barista...), origin (eko / bio...).
- `pakiranje_kolicina`, `pakiranje_jedinica`, `pakiranje_komada`: Pack size in g or ml and pieces per pack (for 'packages needed').

## Known limits

- Estimates (`procjena_*`) are within 10 % kcal of the real label in about 70 % of cases; good for sorting and comparison, not a label. Checks: `reports/nutrijenti_provjera.md`.
- Coffee and tea: labels declare the prepared drink (about 1-3 kcal / 100 ml), CIQUAL the dry product.
- Vegan precision was measured on a stratified sample reviewed by a model (`reports/vegan_audit.md`); recall is not measured.
- Studenac has no Zagreb store in the price archives.
